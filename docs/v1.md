# Townsquare v1

The original single-instance release: a small, self-hostable, old-school social publishing
framework with one domain and one binary.

## What was included

### Publishing

- Profiles with bios, join dates, and locally moderated avatar photos
- Markdown posts and threaded comments, sanitized before rendering
- Channels: general, memes, daily, suggestions, hall of shame, and an 18+ NSFW channel
- Emoji picker and reactions
- Hashtags with tag filtering
- Direct messages with optional blocked-term monitoring
- A Web 1.0 look with tables, serif type, blue links, and a visitor counter

### Community and administration

- Invite-only registration; email addresses are optional
- Rate limiting, CSRF protection, one-time recovery codes, and admin password reset links
- Attack mode: automatic flood lockdown for previously recorded IPs and admins
- Admin panel with stats, invites, users, post moderation, blocked DMs, and a news ticker

### Technical

- Public read API and Bearer-token write API
- RSS feeds and Open Graph metadata
- SQLite storage with WAL mode
- A single Go binary with no external services
- AGPL-3.0-or-later license

## Notes

- v1 is a single instance. Federation between independently hosted towns is not included.
- The visitor counter and site statistics are available in the footer, admin panel, and API.
