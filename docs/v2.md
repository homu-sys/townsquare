# Townsquare v2 — BIG UPDATE

Released as [v2 BIG UPDATE](https://github.com/homu-sys/townsquare/releases/tag/v2).
This release adds staff roles, private bookmarks, mute and block controls, visit markers,
pull-based federation, and browsable API documentation.

## What's new

### Roles and staff

- Four roles: member, moderator, admin, and instance owner
- The first setup account becomes the instance owner
- Existing databases promote the earliest admin to owner once during migration
- Owner, admin, and moderator icons appear beside names in posts, comments, profiles, and user lists
- Moderators can open the staff dashboard, review and delete posts, handle blocked DMs, and delete comments
- Moderators cannot manage users, invites, news, or attack mode
- Admins can promote members to moderator or admin
- The instance owner is protected from demotion, disabling, and password resets through the staff panel

### Mute and block

- Mute someone to hide their posts from feeds and their comments from post pages
- Block someone to hide their posts and close direct messages in both directions
- Manage muted and blocked people from settings
- Mute and block actions are also available from profiles

### Private bookmarks

- Bookmark posts for later
- A private `/bookmarks` page lists saved posts
- Bookmark and remove-bookmark controls are available on post pages

### New since your last visit

- Posts and comments get a `new` marker during a visit window
- Your own posts and comments are never marked new
- Post rows also show how many new comments were added since your last visit

### Pull-based federation

- Show recent public posts from other Townsquare instances under “From other towns”
- Remote instances are configured with `TS_FEDERATION_INSTANCES`
- Refresh interval is configured with `TS_FEDERATION_INTERVAL`
- Each instance exposes `/federation/latest.json`
- This is a lightweight pull-based feed, not full ActivityPub federation

### Visitor tracking

- The footer visitor counter counts unique visitor IPs and records any HTML page load, not just the home page
- A new IP becomes a new visitor; refreshing from the same IP does not increase the count
- Visitor records store the raw IP address in SQLite alongside the hashed attack-mode key
- Page views remain available to admins and through the API as `hits`

### API and documentation

- Added a browsable HTML API reference at `/api`
- Moderators can delete any post through the Bearer-token API
- API documentation reflects the expanded role permissions

## Other improvements

- Visitor counts are shown in the footer; page views remain in the admin panel and API
- Fixed tag listing errors when loading posts for a tag
- Visitor recording runs after attack-mode checks, while visit markers still run after session loading
- Post delete controls are now available to moderators without granting post editing
- Added tests for roles, owner protection, owner migration, mute and block, bookmarks, visit markers,
  federation, and tag pages

## Upgrade notes

- Database migrations run automatically on startup
- The first setup user is created as the instance owner
- On an existing installation, the earliest admin is promoted to the owner role once
- The v2 release includes a Linux amd64 binary: `townsquare-linux-amd64`
